# DocSutra AI

**Offline documentation auditor for Markdown.** Finds broken links, stale heading anchors, case-sensitive path bugs, missing image alt text, leaked credentials, risky shell snippets, and documented CLI flags that do not exist. Writes the audit as **Markdown, HTML, JSON and SARIF**. No API key, no network, nothing executed.

## Quick start

```bash
npx docsutra-ai scan --root .
```

Needs Node.js 20 or newer. It writes `.docsutra/audit.md`, `.docsutra/audit.html` and `.docsutra/audit.json`, and exits `1` if any error is found (use `--fail-on none` to only report).

Sample reports generated by real runs: [broken demo (HTML)](examples/reports/demo-audit.html), [broken demo (Markdown)](examples/reports/demo-audit.md), [healthy repo](examples/reports/healthy-audit.md), [DocSutra auditing its own docs](examples/reports/self-audit.md).

## What it checks

| Category | Rules |
|---|---|
| Links | broken local link, broken heading anchor (GitHub slug rules), path case mismatch, undefined reference link, malformed encoding, link escaping the repo |
| Accessibility | image without alt, empty link text, skipped heading level |
| Structure | unclosed code fence, duplicate headings, unreadable file |
| Commands | documented subcommand or flag missing from your declared CLI contract |
| Security | credentials in docs (redacted in output), `curl \| sh`, destructive commands, unsafe URL schemes |

Full rule list with severities is embedded in every report. The exact Markdown constructs handled are in the [coverage matrix](docs/COVERAGE.md).

## Understand the report

Every report contains:

- **Verdict** and counts by severity.
- **Verification ledger**: for each check, how many were performed, passed and failed. A check that is missing was never run.
- **Findings** grouped by file, with line, context excerpt, suggested fix, evidence method and stable ID.
- **Not checked**: external URLs (never fetched), shell lines (never executed), suppressed findings.
- **Provenance**: tool and rule versions, Node/OS, git revision, SHA-256 input fingerprint and per-file hashes.

A passing report means the supported static checks passed. It does not prove that your documentation is true.

## Commands

```bash
docsutra scan --root . --format all --out-dir .docsutra
docsutra scan --root . --format sarif --out docsutra.sarif
docsutra scan --root . --baseline main-audit.json
docsutra diff --before old.json --after new.json
docsutra install-skills --host claude --target .
docsutra doctor
```

Exit codes: `0` clean, `1` findings at or above `--fail-on` (default `error`), `2` usage, config or runtime error.

## Use in CI

```yaml
- run: npx docsutra-ai scan --root . --format all --out-dir docsutra-report
- uses: actions/upload-artifact@v4
  if: always()
  with: { name: docsutra-report, path: docsutra-report }
```

Gate only on **new** problems by saving the base branch's `audit.json` and passing `--baseline`. Upload `--format sarif` output to GitHub code scanning for inline annotations.

## Configuration

`docsutra.config.json` is strictly validated; unknown keys fail with exit code 2.

```json
{
  "ignore": ["vendor"],
  "ignoreRules": ["HEADING_LEVEL_SKIP"],
  "failOn": "error",
  "cliContracts": {
    "docsutra": { "subcommands": ["scan", "diff"], "flags": ["--root", "--format"] }
  }
}
```

Silence one line with `<!-- docsutra-disable-next-line BROKEN_LOCAL_LINK -->`. Suppressions are counted in the report.

## 16 portable agent skills

`docsutra install-skills` copies skills into the project folders used by Claude Code, Cursor, Codex, Gemini CLI and GitHub Copilot. Each skill says what backs it:

- **CLI-backed** (8): Prime, Link Guardian, CLI Contract, Privacy Guard, Accessible Docs, Snippet Lab (classification only), Evidence Verifier, Drift Radar.
- **Instructions only** (8): Truth Keeper, API Cartographer, Schema Sentinel, Example Forge, Diagram Alignment, Localization, Patch Crafter, Release Notes. No deterministic engine behind them yet; they require cited evidence and honest labels.

Copying files to those folders is **not verified host activation**. See [IDE compatibility](docs/IDE_COMPATIBILITY.md).

## Safety model

Read-only. Never executes commands from Markdown. Never fetches URLs. Skips symlinks. Redacts credentials. Zero runtime dependencies. Details and tested guarantees: [SECURITY.md](SECURITY.md), [threat model](docs/THREAT_MODEL.md).

## Programmatic use

```js
import { audit, toHtml } from 'docsutra-ai';

```
