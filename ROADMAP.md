# Roadmap

1. **P0:** Harden existing scanner; add complete Markdown AST and repo configuration schema; extend security and performance tests.
2. **P1:** Source-backed claim ID and ProofGraph baseline; better CLI help snapshot verification; JSON Schema and code symbol adapters.
3. **P2:** Verified `lychee`, `Vale`, `markdownlint-cli2`, TypeDoc/OpenAPI adapters; no tool duplication.
4. **P3:** Opt-in sandboxed Snippet Lab, reproducible images, resource/network policy and artifact evidence.
5. **P4:** Git-diff-driven Drift Radar, patch preview, provenance and human approval.
6. **P5:** Cross-IDE invocation tests and CI matrix (Claude Code, Cursor, Codex, Gemini CLI, Copilot); reliable fallback.
7. **P6:** Authenticated production server API, role/policy authorization, job isolation and audit records.
8. **P7:** Optional model/agent assistance, internationalized docs, accessibility review and visual dashboard.
9. **P8:** Open-source public beta, benchmarks, reproducible releases and community governance.
