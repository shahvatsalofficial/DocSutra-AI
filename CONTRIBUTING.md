# Contributing

Thanks for supporting DocSutra AI, created by Vatsal Shah. Before opening a PR:

1. Open an issue for substantial new scanners or architecture changes.
2. Include a minimal fixture demonstrating the documentation problem.
3. Run `npm test` and document OS/Node versions.
4. Preserve source-path and test-evidence metadata; add negative security tests.
5. State whether the feature is implemented, experimental or planned.
6. Don't submit AI-generated bulk PRs or publish private repo contents.

Follow the Contributor Covenant principles in `CODE_OF_CONDUCT.md`.
